# Levantamento de necessidades de computador

MVP de interface para estruturar a necessidade de computador antes de definir a compra. O fluxo reúne:

1. Descrição do trabalho, contexto e frequência de uso, tarefas simultâneas e impacto de indisponibilidade.
2. Programas utilizados, atividades, versões e tarefas específicas.
3. Configuração proposta: processador, memória RAM, armazenamento e placa de vídeo, além de necessidades de garantia, suporte, compatibilidade e mobilidade.

Esta versão apenas organiza as informações fornecidas. Não compara requisitos, consulta referências, recomenda equipamentos, verifica conformidade legal nem gera um ETP.
